# LactoLink+ Android app

Download page for the LactoLink+ Android app by LATCH Los Baños, which connects mothers who need
breast milk with screened donors. Donor milk is never sold.

**Download the latest version:**
https://github.com/johnchristianesme/lactolink-releases/releases/latest/download/lactolink-plus.apk

Your phone may ask you to allow installing apps from your browser. On an iPhone, use the web
version: https://lactolink-plus-dev.web.app

This repository only holds the app file. The source code is private.
